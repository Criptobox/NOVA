NOVA · Agente de WhatsApp + Cripto

Página de cortesía · el panel real es una app Next.js (PWA)
¿Por qué el sandbox dice que «no hay página HTML»?
Porque NOVA no es una web estática: es una aplicación Next.js con servidor, base de datos y APIs. Los «enlaces rotos» que señala (tailwindcss, tw-animate-css) son imports de paquetes npm que se resuelven al compilar — no archivos del proyecto. El único lugar que la ejecuta de verdad es Vercel.

Despliegue (solo GitHub + Vercel)

  1. Sube TODOS los archivos del zip al repo de GitHub.
  2. Vercel → Import Project → el repo.
  3. Vercel → Storage → Create Database → Postgres → Connect Project.
  4. Redeploy y abre el panel: las tablas se crean solas.

Qué incluye la app

Agente de WhatsApp (API oficial gratis), cripto en datos reales, control por voz de la tienda, trading en simulación, modo offline, push, CSV y panel claro/oscuro — todo dentro de Vercel.
